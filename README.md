# Intermediate Python Loops & Loop Control Statements

This repository contains practical solutions and exercises covering intermediate Python loop concepts, loop control statements, and pattern generation as part of the **Super30 Python Assignment Series**.

---

## 📌 Topics Covered

- **Loop Control Statements:** `break`, `continue`, `pass`, and `for-else` constructs.
- **Built-in Functions:** `range()` and `enumerate()` for efficient iteration.
- **Nested Loops:** Multiplication tables and complex iterations.
- **Pattern Printing:** Dynamic star (`*`) pattern generation using `for` and `while` loops.
- **Data Manipulation:** Filtering unique elements without built-in functions, categorizing numbers, and conditional checks.
- **Mathematical Algorithms:** Finding factors, divisibility tests, and prime number algorithms.

---

## 💻 Practice Problems & Implementations

### 1. Loop Control (`continue` & `break`)
- **Skip Multiples:** Print numbers from 1–100, skipping numbers divisible by 5 using `continue`.
- **Early Exit:** Iterate from 1–100 and exit immediately upon encountering the first number divisible by both 7 and 11 (returns `77`).

### 2. Search & `for-else` Loop
- Search for a user-specified number within a list and utilize `for-else` to output whether the element was found or not.

### 3. Iteration with `enumerate()`
- Index-value pairing across lists both with `enumerate()` and traditionally using `range(len())`.

### 4. Pattern Printing
- Ascending star patterns using string accumulation and numerical multiplication (`*`).
- Descending star patterns driven by dynamic user input using `while` loops.

### 5. Nested Loops & Logic
- **Multiplication Tables:** Grid tables from 1 to 10 via nested loops.
- **Divisibility Tests:** Identify all numbers between 1 and 200 divisible by both 3 and 5.
- **Deduplication:** Extract unique elements from a duplicate-laden list without using `set()`.
- **Categorization:** Separate positive, negative, and zero values from a dataset into distinct lists with count tracking.

### 6. Prime Number Calculations
- Single-number primality test taking dynamic input.
- Generation of all prime numbers between 1 and 100 using nested evaluation loops.
